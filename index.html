Publishing on GitHub Pages

GitHub Pages hosts static websites. To run Python games in browser, export them to WebAssembly/JS (for example with Pygbag), then link the web build here.

  1. Create a repo per game and upload the web build files.
  2. Enable GitHub Pages in repository settings (deploy from branch).
  3. Copy the page URL (like https://your-username.github.io/game-name/).
  4. Update card links in this portfolio to point to your live game.
